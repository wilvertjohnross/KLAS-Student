# KLAS Student v0.1.2 — GUI Alignment

Visual-alignment prototype for the KLAS Student Portal.

## Branding
- Full KLAS banner is the primary in-environment identity.
- Standalone KLAS icon is reserved for favicon/PWA/app-icon contexts.
- Visual language is aligned to the current KLAS Teacher repository: Segoe UI, navy navigation, classroom imagery, translucent glass launchers, pastel service icons, and responsive mobile navigation.

## Run
1. Open a terminal in this folder.
2. `npm install`
3. `npx vite --host`
4. Open the Local URL on the PC or the Network URL on a phone connected to the same Wi-Fi.

## Scope
Authentication is still a local development shell. Grades, SF9, schedule, and feedback are placeholders pending backend integration.
